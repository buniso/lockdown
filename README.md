# The Lockdown Index — DH101 Group 4 mini-site (draft skeleton)

A draft GitHub Pages version of the World Happiness Report mini-site, to compare against the Wordspace build.

## What's here
- `index.html` — home page, hero (design changed), research questions
- `narrative.html` — full narrative text + placeholders for the timeline, 5+ visualizations, and map
- `bibliography.html` — full annotated bibliography, grouped by team member
- `data-critique.html` — full data critique, grouped by team member's question
- `about.html` — sources/processing/presentation, bios, role table, acknowledgements
- `css/style.css`, `js/main.js` — shared styling + the scroll-driven smiley flip
- `assets/img/` — empty folder, drop illustrations/photos here
- `data/` — empty folder, drop your cleaned CSV(s) here once you're ready to wire up real charts
